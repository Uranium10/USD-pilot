# NAN2026 포지셔닝 초안

## AI를 쓰는 게임에서, AI가 연출하는 게임으로

> **U.S.D는 AI가 한 런의 시장 서사를 계획하고, 매주 플레이어가 마주할 거래 조건을 연출하는 실시간 주식 로그라이크입니다.**

많은 게임이 AI로 대사, 이미지, 배경 설정을 만든다. U.S.D는 생성 결과를 콘텐츠 목록에 추가하는 데서 한 단계 더 나아간다. AI가 사건을 구조화하고, 게임 엔진이 그 사건을 실제 가격 변화와 정보 비대칭으로 실행한다.

```text
7주 전체 사건을 계획하는 AI Showrunner
                  ↓
매주 7일치 사건을 만드는 AI Episode Director
                  ↓
정보 거래소의 단서 → 플레이어의 투자 판단 → LIVE WIRE 뉴스와 가격 변화
```

### AI의 출력이 플레이가 되는 과정

| 일반적인 생성형 AI 활용 | U.S.D의 AI Director |
|---|---|
| 읽고 지나가는 대사 생성 | 매수·매도 판단의 전제가 되는 정보 생성 |
| 독립적인 짧은 콘텐츠 | 7주 동안 복선과 결말이 이어지는 RunPlan |
| 자연어만 출력 | 종목·방향·크기·시점·뉴스·정보의 구조화 출력 |
| 응답을 기다린 뒤 표시 | 다음 주를 미리 생성해 실제 플레이는 즉시 시작 |
| 실패 시 빈 화면 또는 오류 | 검증·재시도·캐시·로컬 fallback으로 계속 진행 |

---

## U.S.D가 잘 살린 세 가지

### 1. AI가 게임의 코어 루프에 들어가 있다

플레이어는 AI 뉴스 자체를 감상하는 것이 아니라, AI가 만든 정보의 신뢰도를 평가하고 돈을 지불한 뒤 실제 포지션을 정한다. 사건이 발생하면 가격과 뉴스로 결과가 돌아온다. AI가 없으면 반복 플레이의 사건 구조와 정보전이 달라지므로, AI는 제거 가능한 장식이 아니다.

### 2. AI 출력이 정보 비대칭을 만든다

주식 게임의 핵심은 모든 정보를 아는 것이 아니라 불완전한 단서로 판단하는 데 있다. 런타임 AI는 같은 사건을 거래 전 정보와 거래 중 뉴스라는 두 시점으로 나눠 제시한다. 플레이어는 정보의 가격과 신뢰도를 평가해 실제 자금을 쓰고, 이후 차트에서 판단의 결과를 확인한다. AI 생성물이 게임의 핵심 자원인 정보 비대칭을 직접 만든다.

### 3. 실제 서비스 가능한 AI 구조를 만들었다

AI의 다음 단계에는 좋은 샘플 한 개보다 반복 호출의 신뢰성이 중요하다.

- 다음 주 시나리오를 약 56분 전에 프리페치
- 사용자별 RunPlan/worldState를 Turso에 영속 저장
- JSON Schema 구조화 출력
- orphan 정보와 뉴스 주체 불일치 검증
- 최대 3회 재시도와 best-result 정책
- 재시작 보호와 중복 생성 방지
- 외부 API 장애 시 결정론적 로컬 시장 fallback
- 동일 RunPlan 14회 실호출로 비용·시간·품질 비교

현재 운영 모델은 기준 모델 대비 주간 비용 58.0%, 시간 30.6%를 줄이면서 라이브 경로 14/14 검증을 통과했다.

## 심사위원에게 전달할 핵심 문장

### 15초 버전

> U.S.D는 AI가 뉴스를 쓰는 주식 게임이 아닙니다. AI가 7주 시장 서사를 계획하고, 그 사건이 정보 상품과 실제 가격 변화가 되어 플레이어의 다음 결정을 만드는 게임입니다.

### 30초 버전

> 저희는 AI를 콘텐츠 생성기가 아니라 게임 디렉터로 설계했습니다. 강한 모델이 한 런의 복선과 결말을 계획하고, 저비용 모델이 매주 7일치 사건을 구조화합니다. 게임 엔진은 이를 실제 차트와 정보 거래로 실행합니다. 다음 주는 미리 생성하고 모든 결과를 검증·재시도하므로, LLM의 지연과 실패가 실시간 플레이를 끊지 않습니다.

### 기술 차별점 버전

> 생성형 AI의 자유도와 게임 규칙의 안정성을 분리했습니다. AI는 사건의 의미를 연출하고, 결정론적 엔진은 가격과 경제 밸런스를 통제합니다. 이 경계 덕분에 매 판 다른 이야기를 만들면서도 플레이 가능한 시장을 보장합니다.

## 발표에서 보여 줄 증거

1. 정보 거래소에서 사건의 단서를 구매하는 화면
2. 같은 사건이 LIVE WIRE 뉴스와 가격 변화로 현실화되는 화면
3. RunPlan → CycleScenario → 시장 컴파일 구조 그림
4. 프리페치 전 약 19.5초, 도달 시 약 0.1초 실측
5. Terra medium과 Luna low의 동일 14회 비교 표
6. orphan rumor·주체 불일치 자동 검증 사례
7. AI 실패 시에도 로컬 시장으로 계속 플레이되는 fallback

---

## 피해야 할 표현

- "AI가 플레이어의 모든 행동을 실시간 학습한다"  
  현재는 플레이어 거래 내역이 아니라 RunPlan과 서사 worldState를 사용한다.

- "AI가 주가를 전부 결정한다"  
  가격 경로와 안전 범위는 결정론적 게임 엔진이 통제한다.

- "가장 저렴한 모델을 사용했다"  
  더 저렴한 후보도 실험했지만 의미 품질 때문에 채택하지 않았다. 품질·비용·속도의 균형으로 Luna low를 선택했다.

- "AI 오류가 없다"  
  오류 가능성을 전제로 검증·재시도·fallback을 설계했다.

이 구분을 지키면 과장 없이도 U.S.D의 설계 완성도를 충분히 어필할 수 있다.
