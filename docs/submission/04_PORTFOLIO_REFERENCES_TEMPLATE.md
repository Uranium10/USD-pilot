## 3. 기술 하이라이트

### AI 서사와 시장의 결합

- RunPlan이 7주 전체 사건을 계획한다.
- CycleScenario가 7일치 뉴스와 정보를 생성한다.
- 결정론적 가격 경로에 사건 방향·크기·시점을 합성한다.
- 같은 사건을 정보 거래소와 LIVE WIRE에서 다른 시점에 경험한다.

> [선택 삽입: RunPlan → CycleScenario → 차트 합성 다이어그램]

### 실시간 UI

- Canvas 기반 차트
- React 외부 시간 진행 엔진
- 뉴스·가격·보유량의 빈번한 갱신에도 안정적인 레이아웃
- 낮/밤/정산/엔딩 상태 전이

### 저장과 복구

- Vercel Functions + Turso
- 서버 저장 revision으로 오래된 요청 차단
- localStorage 보조 백업
- AI 시나리오 프리페치와 재시작 보호

## 4. 문제 해결 사례

포트폴리오에는 결과 화면만 나열하지 말고 문제-원인-해결-검증을 한 세트로 넣는다.

### 사례 A. AI 대기시간 제거

- 문제: 주간 시나리오 생성 15~25초
- 원인: 주차 진입 직전에 LLM 호출
- 해결: AI 시나리오만 주 시작 시 프리페치
- 검증: 최초 생성 19.5초, 주차 도달 시 0.1초

### 사례 B. 주간 모델 비용 최적화

- 문제: Terra medium 14회 기준 $0.5690
- 해결: 스키마 슬림화와 동일 RunPlan 모델 벤치마크
- 결과: Luna low 라이브 경로 $0.2388, 시간 30.6% 감소, 14/14 무결함

### 사례 C. 조용히 사라지는 AI 정보

- 문제: 다른 날짜 eventId를 참조한 정보가 컴파일 시 제거
- 해결: 같은 날 event-rumor 연결 검증과 재시도
- 검증: 자동 검사 추가, Luna low 라이브 14회 orphan 0건
